# Survey: core/infrastructure/ (77 files, 21.5k lines, incl. config/ and language-patterns/)

## 1. Map

- Meant to be the support layer every domain imports. In fact it holds six different things:
  1. Config: `config/*.js` (platform, embedding, ranking, search, graph, vector-store, translation, dedup), `init-config.js`, `constants.js`. Reaches callers through THREE doors: `core/config.js` (14 importers), `config/index.js` (67), `index.js` barrel (`export *`).
  2. Native/ML runtime loaders: `native-resolver.js` (loader), `native-inference.js`, `native-tokenizer.js`, `native-sparse-gram.js`, `native-rescore.js`, `dedup-hashing.js`, `simd-distance.js` (+`.wasm`), `hamming-kernel.js`, `onnx-session-utils.js`, `ort-pipeline.js`, `coreml-*.js`, `hardware-capability.js`, `model-registry.js`, `model-fetcher.js`.
  3. SQLite persistence: `db-utils.js`, `index-schema.js`, `codebase-repository.js`, `code-graph-repository.js` (1419 l), `structural-context-repository.js` (1511 l), `code-graph-visibility.js`, `graph-name-indexes.js`.
  4. Graph/structural domain logic: `structural-*.js` (7 files), `file-nodes.js`, `relationship-types.js`, `import-path-prefixes.js`, `receiver-type-annotation.js`, `test-paths.js`.
  5. Parsing/chunking: `tree-sitter-provider.js` (2888 l), `tree-sitter-doc-comments.js`, `view-templates.js` (1031 l), `language-patterns*` (+ `grammars/`).
  6. Misc: `llm-provider.js` (HCGS summary LLM chain), `cached-json-file.js`, `call-fs.js`, `boot-log.js`, `process-title.js`, `spawn-ledger.js`, `inference-provenance.js`, `inference-parity.js`, `maxsim-pack.js`, `tombstone-bitmap-reader.js`, `sparse-gram-delta-reader.js`, `manifest.json`, `coreml-cascade.json`.
- Import graph from outside the folder: 395 deep imports of single files, 67 via `config/index.js`, 14 via `core/config.js`, 30 via the `index.js` barrel. The barrel is bypassed 13:1.
- `scripts/check-boundaries.js:36` forbids infrastructure -> embedding/indexing/search/ranking/graph/vocabulary/vector-store/query/prompt-optimization, but NOT `agent-tools/`, so the 3 upward imports pass.
- Real entry points: `config/index.js`, `db-utils.js`, `native-resolver.js::loadNativeAddon`, `model-registry/fetcher`, `native-inference.js`, `code-graph-repository.js`, `tree-sitter-provider.js`. Used by every domain, `scripts/` (42 imports), `mcp/` and `eval/`.

## 4. Redesign ideas

1. Shrink "infrastructure" to what is stable: env/flags, paths and settings, native addon loader, model registry/fetcher, db-utils. Move everything that changes with the graph/chunker (structural-*, tree-sitter-*, view-templates, language-patterns, code-graph-repository, llm-provider, file-nodes, relationship-types, test-paths) to the graph domain with the schema and its readers/writers under one owner (this alone removes the schema-by-comment link and the two read layers).
