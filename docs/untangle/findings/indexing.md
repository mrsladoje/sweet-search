## 1. Map
- Purpose: build and maintain the index (chunks, vectors, code graph, late-interaction (LI) tokens, sparse-gram grep data, HNSW artifacts) for one project, plus the background "maintainer" daemon and worktree index cloning.
- Batch path (entry `index-codebase-v21.js`, run as `node core/indexing/index-codebase-v21.js`; callers: package.json `index`, core/cli.js, mcp/tool-handlers.js:301, scripts/benchmark-*.js, eval scripts): `indexer-phases.js` (phase runner, device/pool decisions) -> `indexer-build.js` (graph, vector schema, chunkFiles, insert) / `streaming-vectors.js` (big repos) / `indexer-ann.js` (LI + HNSW + quant) / `artifact-builder.js` / `indexer-sparse-gram.js` / `dedup/`.
- Chunkers: `ast-chunker.js` (code, tree-sitter), `document-chunker.js` facade -> `chunking/{markdown,plaintext}-chunker.js` + `chunk-builder.js`; `chunking/view-chunker.js` (Razor/ASPX).
- Inference plumbing: `indexer-pool.js` + `indexer-worker.js` (embedding/LI worker threads), `model-pool.js` + `index-device-choice.js` + `index-device-probe-child.mjs` (measured CPU-vs-accelerator test), `encoder-client.mjs` + `encoder-host.mjs` + `encoder-ops.mjs` (encoder child process, used at QUERY time by core/search/query-encoder*.mjs).
- Change detection / policy: `incremental-tracker.js` (full-build state, file name is `merkle-state.json`), `config-fingerprint.js`, `index-format-versions.js`, `admission-policy.js`, `grep-corpus.js`, `indexing-file-policy.js`, `minified-detector.js`, `gitignore-filter.js`, `changed-files-tracker.js`.
- Daemon: `index-maintainer.mjs` (1812 lines: lock, takeover, recycle, idle TTL, watcher, reconcile ticks), `maintainer-launcher.mjs` (spawn/supervise; imported by search-server, mcp, index-codebase-v21), `maintainer-watcher.mjs`, `rss-budget.mjs` (daemon RSS registry, used by search daemon), `os-priority.mjs`.
- Worktrees: `worktree-index.mjs` (CoW clone of main index; used by mcp/server.js, eval helpers).
- Callers into the folder from outside: core/search (encoder-client, rss-budget, maintainer-launcher, changed-files-tracker, admission-policy, grep-corpus, chunk-text-fts), mcp, core/cli.js, scripts, eval. Barrel `index.js` has only 2 non-test importers (scripts/ast-chunker-cli.js, eval/scripts/freeze-pattern-chunk-ids.js).
- core/indexing -> core/incremental-indexing: 31 edges, 14 files (hashing, file-state-store, manifest, path-filter, worktree-stamp, sparse-gram-delta, interval-autotune, reconciler pieces). Reverse: 12 edges from dirty-scan, production-reconciler, production-li-delta, baseline-readiness, sparse-gram-fold, vector-delta-writer back into indexing (admission-policy, grep-corpus, indexing-file-policy, config-fingerprint, chunk-text-fts, indexer-build, ast-chunker, indexer-ann, indexer-sparse-gram). The two folders are one feature split by "full vs incremental".
- Import cycle (5 files): chunk-builder -> ast-chunker -> document-chunker -> markdown-chunker/plaintext-chunker -> chunk-builder.
- Unresolved imports from graph-report (item 7) are NOT live: indexer-build.js:44 is a JSDoc `import('../../ast-chunker.js')` type (wrong path, comment only); indexer-pool.js:28 is inside a comment. No runtime break.
