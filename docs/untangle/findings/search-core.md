## 4. Redesign ideas
- One `AgentFormat` module: `isAgentFormat(opts)`, `formatTier(format)`, a tier table (budget, related rows, reserve fraction, caps); delete `_isAgentFormat` as a second flag and the 9 spelled sets. Then the CLAUDE.md gating rule has one call site.
- Split context-expander.js into span-expansion/staleness/header primitives (used by grep path and indexer), sufficiency, graph-neighbour/related rows, budget tiers, and a thin packageForAgent. Break the grep path -> packager dependency.
- Replace the prototype mixin and the underscore-cache options with an explicit pipeline: `SearchContext` (caches, normalised ablations, format flags, timings) passed to stage functions; stages become pure functions of (results, ctx).
- Delete knobs nothing sets (env weights, ~30 ablations, deprecated hybridSearch, SmartSearch, codebaseDb, collapse experiment) and keep one `tuning` constants file; shared `text-terms.js` for stopwords and identifier splitting.
