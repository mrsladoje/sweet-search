# Findings: ranking-stores (core/ranking, query, vocabulary, vector-store, embedding + training/query-router product part)

## 1. Map
- core/ranking (8.9k): `file-kind-ranking.js` (2663 lines: file-kind classify, query-intent regexes, entity-kind inference, symbol/path/identifier boosts, demotions; reads source files from disk), `late-interaction-index.js` (2539: SSLX segment store, quantisation, MaxSim scoring), `late-interaction-model.js` (873: LI encoder singleton, CPU/GPU encode), `late-interaction-policy.js` (when LI rerank is on), `flashrank.js` (Reranker facade over FlashRank/Voyage/Jina/local), `local-reranker.js`, `cascaded-scorer.js`, `mmr.js`, `quality-scorer.js`.
- core/query (1.2k): `query-router.js` (live: WASM CatBoost in crates/wasm-router/pkg + `looksLikePath`), `intent-router.js` (live: retrieval policy), `intent-detector.js` (live only for graph-search), `query-router-ml.js` + `query-router-catboost.js` (not used by product).
- core/vocabulary (3.9k): miner (`vocab-miner*.js`) -> ranker -> warmer/orchestrator -> artifacts (`vocab-constants.js`); `vocabulary-utils.js` is an older standalone pipeline.
- core/vector-store (4.5k): `binary-hnsw-index.js` (JS graph + native Rust searcher/builder), `full-vector-file.js` (f16 rescore vectors), `float-vector-store.js` (default-off Stage 2.5), `seismic-index.js` (placeholder), heaps, delta file, header.
- core/embedding (3.7k): `embedding-service.js` facade, `embedding-local-model.js` (CodeRankEmbed ORT/native), `embedding-remote.js` (Voyage/Mistral/Jina), `embedding-cache.js` (LRU + Vocabulary + SemanticCache + dedupe), `model-server/client.mjs` (shared RPC server).
- Real entry points: search path uses `core/search/*` importing files directly (`file-kind-ranking`, `mmr`, `quality-scorer`, `late-interaction-*`, `flashrank`, `local-reranker`, `query-router`, `intent-router`); indexing/incremental-indexing import `late-interaction-index/model`, `binary-hnsw-index`, `float-vector-store`, `embedding-*`; `core/cli.js` imports the vocabulary barrel; `incremental-indexing/maintenance-handlers` imports `refreshVocabulary`.
- Barrels: only scripts/ and tests import `ranking/index.js`, `vector-store/index.js`, `query/index.js`. No product code imports `vocabulary/index.js` except `cli.js`. `ranking/index.js` omits `file-kind-ranking.js` and `late-interaction-policy.js`, the two most-used modules.
- Product depends on `core/training/query-router/`: `core/query/query-router-catboost.js` imports `output/v46_router_d4.js` and `features/extractor.js`; both folders ship in package.json `files`.
