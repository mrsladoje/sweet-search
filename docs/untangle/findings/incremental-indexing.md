# Findings: core/incremental-indexing/ + core/indexing/index-maintainer.mjs

## 1. Map
- Purpose: keep an existing full index current after edits. A daemon (the "maintainer") ticks every 10-20 s: scan/queue dirty files, hash, re-chunk, then write per-tier deltas (vectors+graph in SQLite, binary HNSW, late-interaction (LI) segments, sparse-gram deltas). It publishes a manifest epoch. Idle ticks schedule maintenance jobs (compaction, GC, merges) from watermarks.
- Real entry points: `core/indexing/index-maintainer.mjs` (1812 lines: lock, recycle, RSS/idle TTL, watcher, tick loop, inline drain) -> `application/production-reconciler.mjs` (1656) -> `application/reconciler.mjs` (generic tick driver, one adapter only). Operator CLI: `application/operator-cli.mjs`, loaded by `core/cli.js:30,90` (dynamic import). Launcher: `core/indexing/maintainer-launcher.mjs`.
- Maintenance side: `domain/watermark-scheduler.mjs` (decides) -> `application/maintenance-worker.mjs` (queue, retries, dead-letter) -> `application/maintenance-handlers.mjs` (executes: hnsw compaction, sparse fold, LI merge, vector/graph GC, pagerank, vocab).
- Infrastructure (27 files): manifest, hashing, file-state-store (sqlite), dirty-set, path-filter, baseline-readiness, reader-heartbeat (reader pin), delta writers (vector, sparse-gram, LI), tombstone bitmaps, GC.
- Domain (6): chunk-identity, encoder-input (hash recipe), interval-autotune, watermark-scheduler, counters, encoder-deps (test-only).
- Product importers from outside: `core/indexing/*` (31 edges: incremental-tracker, merkle-tracker, indexer-phases, indexer-sparse-gram, indexer-manifest, config-fingerprint, admission-policy, grep-corpus, worktree-index import hashing/manifest/path-filter), `core/search/*` (search-reader-pin, setup-status read the manifest), scripts/incremental-soak/*.
- Direction problem: the full indexer (stable) imports from this folder (volatile): see the N entry on direction.

## 4. Redesign ideas
- Split by change axis, not layer: (a) `tick/` (dirty scan, reconcile, per-tier delta writers, manifest publish) and (b) `maintenance/` (watermark decision, queue, handlers, state reader, GC).
- One "artifact layout" module: file names, manifest field names, segmented-LI stub shape. It replaces ~30 file-name literals and raw manifest-field reads.
- Make the full build and the tick share row writers: one `insertEntity`, `makeId`, `pickLiInput`, symbol-mask, relationship insert. Then parity follows from the code, not from comments.
- Move shared primitives (hashing, hash-algorithm, manifest, path-filter/admission, file-state-store) out to a neutral index-core folder; incremental then depends only downward.
- Delete the test-only/legacy set (lockfile, hcgs-invalidation, encoder-deps, schema-migrations, tombstone-injector, legacy-LI branches, `legacy:` row key) and the env overrides nothing sets.
