# Findings: rust-native (Rust crates, native/, JS loaders, MaxSim/HNSW/router tiers)

## 1. Map
- `crates/sweet-search-native` = one napi addon (.node). Modules: `maxsim/` (rayon pool + NEON/AVX2/AVX-512 kernels), `hnsw_search.rs` (HnswSearcher, Hamming scan, int8/full cascade), `hnsw_build.rs` (parallel build), `rescore.rs` + `full_vectors.rs` (int8/f32 dot, f16 file mmap), `inference/` (candle/Metal/CUDA/CoreML embedding + late-interaction models), `tokenizer.rs`, `dedup/`, `sparse_gram.rs`/`native_grep.rs`/`lane/` (grep; other agent).
- JS loads the SAME .node from 8 separate places, each with its own cache + `validate` callback: `core/infrastructure/native-{inference,tokenizer,rescore,sparse-gram}.js`, `dedup-hashing.js`, `simd-distance.js`, `hardware-capability.js`, `core/vector-store/binary-hnsw-index.js` (x2), `core/search/grep-lane.js`. All go through `native-resolver.js`.
- MaxSim product path: `core/ranking/late-interaction-index.js:1870-1990` -> `simd-distance.js` -> native `maxsimScorePacked` (T1) -> wasm-maxsim per-token kernels (T2) -> JS 4-bit LUT / JS dequant + `wasmMaxSimF32` (T3). Token-weight mode is JS only.
- HNSW product path: `binary-hnsw-index.js` -> native `HnswSearcher` (default) ; JS heap walk + `hamming-kernel.js` (wasm/SWAR) when addon missing or `SS_FIX_HNSW_NATIVE=0`. Build: native `buildBinaryHnsw` else JS.
- Query router live path: `core/query/query-router.js` -> `crates/wasm-router/pkg` (committed wasm-bindgen output; Rust `features_v2.rs` + `catboost_v2.rs`). JS CatBoost router (`query-router-catboost.js`, `core/training/query-router/output/v46`) and `query-router-ml.js` are not on the product path.
- `crates/sweet-search-cli` = Rust launcher/thin client (3.2k-line main.rs, no dependency on any other crate); talks HTTP over unix socket to the JS daemon, mirrors many JS functions by hand.
- `native/bg-priority`, `native/mem-pressure`: separate small napi addons. Built in package.json/CI.
- Entry points: `loadNativeAddon()` (native-resolver.js:145), `build:*` npm scripts, `release.yml`, CUDA publish workflows.
