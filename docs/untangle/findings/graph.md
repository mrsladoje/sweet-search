## 4. Redesign ideas
1. One "graph store" module that owns the schema, id minting/parsing, live-row visibility SQL, and row writes (entities, relationships, call_sites, files, FTS). Full build, maintainer, search, trace all call it. Removes: the two insert paths, the 3 id recipes, 8 visibility copies, DDL in graph-extractor, repeated table names in ~30 files.
2. A per-language descriptor table (one file per language, or one object per language) holding scan separators, keywords, quote rules, import scanner/resolver, receiver patterns, bare-call scopes, tree-sitter quirks. The generic modules read it. Adding a language becomes one file.
3. Move the trace domain (structural-context + structural-* + repository) into one folder; keep infrastructure for connections/schema only.
4. Delete: HCGS (generator, summary-manager, columns, CLI), graph-search find* engine (after checking router), three inline CLIs, barrel (or enforce it), experiment env switches, name-index fallback.
5. One test-path predicate (test-paths.js) and one extension->language map.
