## 4. Redesign ideas
- One installer registry: each installer module exports `{id, files, install(ctx), remove(ctx), plan(ctx), ownedPaths}`; init, uninstall plan/execute, help text and `TRACKED_CREATED_PATHS` all iterate it. Pull the prewarm hook, Codex hook and sweet-index skill into modules of the same shape. This fixes problems 1, 2, 3, 6 and the init.js size.
- `scripts/lib/` (or core/setup/) for the shared bits: writeAtomic, readJson, fileState, sentinel, project-root, settings.json hook editor (ownership by command), DATA_DIR_NAME. Then core never imports `scripts/init.js`.
- Split the folder into `scripts/` (shipped product only, flat) vs `tools/` or `eval/scripts/` (experiments) vs `tools/build/`. `files` then lists two directories, not 18 filenames.
- Move bench-only exports (v1 lean constants, prompt EDIT pairs, opencode bench plugin) out of shipped installers into eval/.
- Fix the 7 broken imports or delete the scripts; add `eslint --rule import/no-unresolved` (or a tiny import-resolution test) over scripts/, crates/*/ js and eval/ so this cannot recur.
