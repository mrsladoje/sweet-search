## 0. How to use this file

1. Find the family. Read the row. If your candidate has the same mechanism, it is that row.
2. A row is only revived by its own **revival condition**, not by a new argument.
3. `sweet-only?` says whether the change can create a head-to-head difference at all. A change
   delivered through the shared benchmark prompt, the shared `run_tests` shim, or a shared
   harness setting reaches both arms and has **zero differential** (`BRIEF.md` rule 6).
4. Verdict vocabulary: **DEAD** (killed at a gate with a recorded fact), **CLOSED** (a
   measurement or an owner closed the whole class), **SHIPPED** (in production, not a new
   lever), **INVERTED** (replay or an earlier report said win, the better measurement said
   loss), **PARKED** (allowed, nobody has run its `$0` screen), **OPEN** (a `$0` question
   nobody has answered), **BLOCKED** (cannot be evaluated as specified), **OWNER-EXCLUDED** (a
   decision, not a measurement), **UNMEASURED** (asserted, never measured).
5. Numbers carry tags: `[M]` measured, `[C]` read from code, `[W]` web, `[I]` inferred.
