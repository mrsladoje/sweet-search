# Sweet-search — code search tool guide

Sweet-search provides index-backed code search tools. Prefer them over raw grep/ripgrep and blind file reads for code search and navigation. Report findings in [[agent-format]].

## Tools
- **[[ss-search]]**: hybrid NL retrieval over the codebase.
- **[[ss-find]]**: regex-pattern file search.
- **[[ss-semantic]]**: in-file span retrieval.
- **[[ss-trace]]**: call graph for a known symbol (callers, callees, impact).
- **[[ss-grep]]**: literal regex across all files.
- **[[ss-read]]**: read a specific file.

## Approach
Try [[ss-search]] first. If it doesn't return a useful result, try [[ss-find]] or [[ss-grep]]. Use [[ss-semantic]] to pin a span after a file is located. Use [[ss-trace]] for call-graph queries.

## Output
Report [[expectedFiles]], [[expectedSymbols]], and [[expectedFacts]]. Report [[no-match]] only after a symbol search and a broad [[ss-grep]] both come up empty.
