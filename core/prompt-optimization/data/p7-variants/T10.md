## Tool routing with shape guidance

### [[ss-search]] — route first, shape by family

Default call for NL queries. Apply family-conditioned shaping:
- **C-family (C / C++ / Zig):** For files in the C-family family: Use a medium interrogative query (9-15 tokens) that includes the symbol verbatim.
- **JS-mobile (JS / TS / Dart):** For files in the JS-mobile family: When the target symbol is known, phrase a short interrogative query (4-8 tokens) that includes the symbol verbatim.
- **All other families (default):** Use a medium declarative phrase (9-15 tokens) that includes the symbol verbatim and domain-specific terms.

### [[ss-find]] — symbol-anchored regex with family shape

- **JS-mobile (JS / TS / Dart):** [JS-mobile-override] For ss-find: build the regex as definition-anchored: `\b<family-keyword>\s+<symbol>\b` — language-keyword + symbol; catches the def site AND phrase the semantic query as short interrogative + symbol verbatim (4-8 tokens) — e.g., "how does <Symbol> work".
- **All other families (default):** [simple-global] For ss-find: build the regex as word-bounded literal: `\b<symbol>\b` — the canonical narrow anchor AND phrase the semantic query as short imperative + symbol verbatim (4-8 tokens) — e.g., "find <Symbol> usage".

### [[ss-semantic]] — file-scoped span retrieval

For ss-semantic (in-file span retrieval): phrase a very short imperative query consisting of the target symbol verbatim, optionally with one descriptor word (≤ 3 tokens).

C-family override: For ss-semantic: phrase a short interrogative query (4-8 tokens) that contains the target symbol verbatim. Use "how does X …" / "where is X …" framing.

Use [[ss-semantic]] only after a file is confirmed. Never as a first call.

### [[ss-trace]] — the symbol-not-query contract

[[ss-trace]] is symbol-in / structural-context-out. Call when you already know the target symbol and want callers, callees, and impact paths in one response. CLI: `sweet-search trace <symbol> [--in <file>] [--depth N] [--budget N]`. Pass the symbol verbatim — do NOT phrase as an NL question. Default options (maxDepth=3, adaptive 4k/8k/12k budget) are optimal across all 18 indexed languages: dev callers R@5=0.71, callees R@5=0.94, impact R@5=0.55 against graphNeighbors-derived gold (n=105 dev probes, 21 PASS callees, 27 PASS callers, 21 PASS impact). Add --in <file> when the symbol is ambiguous across files (Vec, Mux, get, App, Use have ≥2 entity rows in the indexed corpora).

**Contract rule:** NEVER call [[ss-trace]] with an NL question as input. NEVER call [[ss-trace]] before confirming the symbol name via [[ss-search]] or [[ss-find]]. The symbol-not-query contract is absolute.

### [[ss-grep]] and [[ss-read]]

Use [[ss-grep]] for literal regex sweeps. Use [[ss-read]] to verify file content or extract surrounding context.
