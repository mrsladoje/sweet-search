# Sweet-search — code search tool guide

Sweet-search provides index-backed code search tools. Prefer them over raw grep/ripgrep and blind file reads for any code search, navigation, or discovery — they are faster and semantic. Fall back to plain grep/read only for changes not yet indexed (e.g. uncommitted edits) or when these tools return nothing. Apply tool-routing discipline and family-conditioned shaping together, and respect the [[ss-trace]] symbol-not-query contract.

## Calling the tools
Invoke via the shell (Bash). `[[ss-search]]`/`[[ss-find]]` return ranked code blocks inline; `[[ss-grep]]` is file:line only:
- [[ss-search]] → `ss-search "<query>" [-k N]`
- [[ss-find]] → `ss-find "<query>" --regex "<regex>" [-k N]`
- [[ss-semantic]] → `ss-semantic <file> "<query>"`
- [[ss-trace]] → `ss-trace <symbol> [--in <file>]`
- [[ss-grep]] → `ss-grep "<regex>" [-k N]`
- [[ss-read]] → `ss-read <file> [start] [end]`

## Tool routing with shape guidance
### [[ss-search]] — route first, shape by family
Default call for NL queries:
- **C-family (C / C++ / Zig):** medium interrogative (9–15 tokens), symbol verbatim.
- **JS-mobile (JS / TS / Dart):** short interrogative (4–8 tokens), symbol verbatim.
- **Default:** medium declarative (9–15 tokens), symbol verbatim + domain keyword.

If the target symbol or file is unknown, lead with domain terms (Default shaping) and switch to symbol-anchored shaping once a candidate symbol appears.

### [[ss-find]] — symbol-anchored regex, family-shaped
- **JS-mobile:** definition-anchored `\b<keyword>\s+<symbol>\b`; short interrogative + symbol (4–8 tokens).
- **Default:** word-bounded `\b<symbol>\b`; short imperative + symbol (4–8 tokens), e.g. "find <Symbol> usage".

### [[ss-semantic]] — file-scoped span
Query with the symbol alone (≤3 tokens); C-family uses a short interrogative (4–8 tokens) with the symbol. Only after a file is confirmed; never a first call.

### [[ss-trace]] — symbol-not-query contract
Pass the symbol verbatim for callers, callees, and impact in one call; add `--in <file>` when ambiguous across files. In Python/Ruby/PHP, prefer callers/callees over impact — impact is unreliable there.
**Contract:** NEVER call [[ss-trace]] with an NL question, and NEVER before confirming the symbol via [[ss-search]] or [[ss-find]].

### [[ss-grep]] and [[ss-read]]
[[ss-grep]] for literal regex sweeps; [[ss-read]] to verify or expand context.

## Routing flow
```
# routing policy pseudocode — NOT executable code
shape query per family → [[ss-search]]
if result is file-only: follow with [[ss-semantic]] (family-shaped)
if [[ss-search]] empty: [[ss-find]] (family regex)
if symbol confirmed AND call graph needed: [[ss-trace]] with symbol verbatim
[[ss-grep]] as literal fallback
```

## Stopping
Stop once evidence is confirmed. If an attempt fails, change approach rather than repeating a near-identical query. Conclude [[no-match]] only after verifying absence (a symbol search and a broad [[ss-grep]] both empty).
